# macOS-27 icon theme

Application artwork from https://github.com/zagnut531/macOS-27-Icons,
using the existing local import from 2026-11-07: Beta 5 with the 27.2
Music update. MANIFEST.json records source paths and Linux icon aliases.
The PNGs are supplied at 16–512 px; aliases share the same artwork.
The import has not been checked against newer upstream changes.

MacTahoe-dark supplies missing applications, symbolic icons and toolbar
actions. places/scalable links to the bundled MacTahoe folder SVGs so
MacShell folder colors and styles keep working. GTK 3, GTK 4, Qt and
Launchpad use this theme by default.

These Apple application icons retain their original rights. The source
repository does not supply a license granting rights to the artwork;
the MacShell MIT license and MacTahoe GPL license do not cover these PNGs.
