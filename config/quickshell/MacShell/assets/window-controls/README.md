Window button artwork copied unchanged from the active Nautilus theme:

`~/.local/share/macshell/nautilus/themes/MacTahoe-{Light,Dark}/gtk-4.0/windows-assets/`

The GTK stylesheet uses 16 px images, 1 px horizontal margins per button,
and 6 px spacing. WindowControls.qml uses the original 2x PNGs at 16 px,
including hover, pressed, inactive, and restore states.
